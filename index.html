Written once, in plain text

No database, no build step, no account. A question is a few lines of YAML, and every study mode reads the same file.

# data/unit2-part2-practical.yml
- id: 3
  image: "practical-2-2/03.jpg"
  question: "What is the red vessel?"
  answer: ["right axillary artery"]
  definition: "The right subclavian artery
    becomes the right axillary artery."
  tags: ["blood-vessels", "artery", "vessels-8"]
  • Tags do the routing The same question lands in a flashcard deck, a four-question quiz, or a full practical depending on how you filter it. You never copy a question twice.
  • Answers accept how people actually write A question can take several correct phrasings, and near-misses earn partial credit instead of a flat zero — because "tunica externa" spelled slightly wrong is not the same as not knowing it.
  • Runs anywhere static files run Vanilla HTML, CSS, and JavaScript on GitHub Pages. It loads on a bad lab connection and costs nothing to host.
